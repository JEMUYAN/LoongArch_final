# 本题的选择排序与归并排序

两份源码均针对 `A[128]`（`0x1c400000`）和题目要求的输出 `B[128]`（`0x1c401000`），且按 `u32` **无符号升序**排列。

| 实现 | 源码 | 时间复杂度 | 额外 ExtRAM | 特点 |
| --- | --- | --- | --- | --- |
| 选择排序 | `selection_sort.s` | `O(N²)` | 无 | 程序短、交换次数少，适合作为第一个完整排序实现。 |
| 归并排序 | `merge_sort.s` | `O(N log N)` | 512 B (`0x1c402000`) | 大数组更快；需要双缓冲、合并和边界控制。 |

## 选择排序的核心

先复制 `A -> B`。外层固定位置 `i`，内层扫描 `[i+1, N)`，以 `min_index` 记录最小元素下标；扫描结束后交换 `B[i]` 和 `B[min_index]`。

比较条件必须是 `B[j] < B[min_index]` 的无符号形式：

```asm
bltu $value_j, $value_min, .Lnew_min
```

不能用 `blt`：例如 `0x80000000` 在有符号语义中是负数，却应排在 `0x7fffffff` 后面。

## 归并排序的核心

使用自底向上（非递归）形式，避免栈和函数递归：

```text
初始：B 中的每个元素都是一个长度为 1 的有序段
width = 1:  合并 [0,1) 与 [1,2)，[2,3) 与 [3,4) ...，写 TMP
width = 2:  合并 TMP 中相邻长度 2 的段，写 B
width = 4, 8, 16, 32, 64：重复，src/dst 每轮交换
最后：若最终数据在 TMP，复制 TMP -> B
```

每次合并维护三个游标：`left`、`right`、`out`，以及两个终点 `mid`、`right_end`。只要两段都未耗尽，就加载两个候选值：

```asm
ld.w  $left_value,  $left,  0
ld.w  $right_value, $right, 0
bltu  $right_value, $left_value, .Ltake_right
# 否则取 left；“相等时取左”使其稳定
```

一段耗尽后，直接复制另一段的剩余元素。段尾可能不足 `width`，故 `mid` 和 `right_end` 都必须截断到 `src_end`；这是归并排序最关键的边界。

## 本题归并排序的临时区

`merge_sort.s` 额外写 `0x1c402000–0x1c4021ff`。当前题目的 `extram_init.bin` 在此区域之后仍有空间，且该程序会在每轮完整覆盖它；顶层无需初始化临时区。

若官方题目不给临时 RAM，不能直接套用该实现；此时选择排序、插入排序，或设计原地归并才符合内存约束。
