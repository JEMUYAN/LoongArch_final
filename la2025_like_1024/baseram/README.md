# BaseRAM 读写验证版：2025 同款数组计数题

此目录用于验证 **BaseRAM 的取指、连续读和最终写回**，不访问 ExtRAM，也不依赖 supervisor。

## 地址布局

| 资源 | 地址 | 内容 |
|---|---:|---|
| 复位 PC / 程序 | `0x1c000000` | `reference_program.bin` |
| 输入数组 A | `0x1c010000` | 1024 个 little-endian `uint32_t`，4096 B |
| 输出结果 | `0x1c011000` | 一个 little-endian `uint32_t` |

题目是统计 `A[0]` 在 `A[0..1023]` 中的出现次数。期望结果是 `19`，因此结果地址的四字节应为 `13 00 00 00`。

## 推荐加载方法

最方便的方式是把 `baseram_image.bin` 从 BaseRAM 基址 `0x1c000000` 开始加载。它是一个 69636 B 的连续镜像：

- 偏移 `0x00000000`：标准程序（48 B）；
- 偏移 `0x00010000`：输入数组；
- 偏移 `0x00011000`：初始清零的结果槽。

然后让 CPU 从 `0x1c000000` 复位。程序写完结果后会原地死循环，测试平台/仿真 testbench 读取 `0x1c011000`。

如你的仿真器分别初始化指令和数据存储器，则使用：

- `reference_program.bin` 写至 `0x1c000000`；
- `input_1024_u32_le.bin` 写至 `0x1c010000`；
- 结果槽 `0x1c011000` 先清零。

`reference.s` 是标准汇编解；它先读取 `A[0]`，再扫描完整 1024 个元素。输入数据与 ExtRAM 版本相同，只有挂载地址不同。
